MOST IMPORTANT REQUIREMENT: UI/UX
==================================================

I want this application to visually feel like it had a $100,000+ professional product design budget: premium, elegant, minimal, clean, sophisticated, modern, extremely easy to understand, highly usable, consistent, spacious, polished, fast, trustworthy.

Reference in spirit (never copy): Linear, Stripe, Notion, Vercel, Ramp, Attio, Intercom. Create an original visual identity.

Follow these design principles throughout:
1. Simplicity over decoration — every element must have a purpose.
2. Clear visual hierarchy — what's important, what needs attention, what to do next.
3. Generous white space, never cramped.
4. Typography: Inter or Geist, clear hierarchy (page title / section heading / supporting text / metadata).
5. Restrained palette: deep navy/indigo primary, neutral grays, professional green (success), warm amber (warning), muted red (danger). No rainbow colors, no neon, minimal gradients.
6. Subtle borders, subtle shadows only when necessary, tasteful rounded corners.
7. Lucide icons only — never emoji as UI icons.
8. Clear button hierarchy: primary / secondary / tertiary / destructive.
9. Every empty state must look intentional and helpful — never a blank screen.
10. Skeleton loaders for loading states; buttons show loading states and disable to prevent double submission.
11. Polished error states — never raw stack traces to users.
12. Subtle, fast micro-interactions (hover, focus, modal/dropdown transitions, toasts) — never gamey.
